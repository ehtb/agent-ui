Start here

Install agent-ui, write the first page and run the checks.

agent-ui is a UI library for apps that an agent writes and maintains. The interface is a JSON spec, state is plain data in namespaces, and all behavior goes through named, typed actions. This page gets you from an empty folder to a checked, server-rendered page.

⚡
Already have an agent on the project?

Run npx agent-ui init to write the operating rules into AGENTS.md, then point the agent at this page and the API reference.

1

Install the package

agent-ui has no runtime dependencies. Add it to a project that uses ES modules and Node 22 or newer.

terminal
npm install @ehtb/agent-ui
2

Describe the build

A project has one build.config.mjs. It returns the framework options for the current mode; your own options come on top.

build.config.mjs
import { dirname } from 'node:path';
import { fileURLToPath } from 'node:url';
import { frameworkBuildOptions } from '@ehtb/agent-ui/build/presets.mjs';

const projectRoot = dirname(fileURLToPath(import.meta.url));

export default ({ dev = false, validator } = {}) => ({
  ...frameworkBuildOptions({ dev, validator, projectRoot }),
});
3

Write the first page

A page is a URL, a URL is a folder, and a page is two files: page.js for behavior and view.js for content. The page at / lives in pages/.

pages/page.js
export const namespaces = {
  todos: {
    state: { items: [], nextId: 1 },
    actions: {
      add: {
        args: { text: 'string' },
        run: (store, { text }) => {
          const id = store.get('nextId');
          store.set('nextId', id + 1);
          store.set('items', [...store.get('items'), { id, text }]);
        },
      },
    },
  },
};

export const page = { head: { title: 'Todos' }, namespaces };
pages/view.js
import { main, h1, ul, li, item, each } from '@ehtb/agent-ui/spec';

export const view = main(
  null,
  h1(null, 'Todos'),
  ul(null, each('todos.items', 'id', li(null, item('text')))),
);

The view imports the builders, but a production browser never does: the build evaluates the view once in Node and ships the finished spec as data.

4

Check it, then build it

The check renders every page in development mode and reports spec, link and data problems. Fix every line it prints before you continue.

terminal
npx agent-ui check
npx agent-ui build
npx agent-ui serve

For a site with no server, npx agent-ui build --static writes one HTML file per URL. Put the output on any file host.
